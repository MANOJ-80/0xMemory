Memory lifecycle

Active → stale → verified or superseded

  • Remember a decision and its supporting file/commit.
  • Observe a committed code change.
  • Review the evidence: retain the statement or replace it.
  • Normal recall excludes stale and superseded entries.
Speaker notes

A file change does not prove the statement false. Still-valid decisions use verify; changed decisions use supersede.

Controlled experiment B

Calibrate a relevance gate, then freeze it.

  • 24 new questions: 8 development + 16 reserved
  • Balanced answerable and unanswered cases
  • Cosine cutoff selected only on development data
  • Threshold 0.25; full grid and selection rule preserved
Speaker notes

The policy minimizes twice the missed-answer rate plus no-answer false positives, with lower-threshold tie breaking. Cosine is not a probability of correctness.
